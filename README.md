# AI Rate My Professor 

AI Rate My Professor is an intelligent professor rating system that leverages Python, Retrieval-Augmented Generation (RAG), Weaviate vector search, and OpenRouter APIs to provide natural language access to professor reviews and feedback.

---

##  Tech Stack

- Python  
- Weaviate (Vector Database)  
- RAG (Retrieval-Augmented Generation)  
- OpenRouter API (LLM Access)

---

##  Features

- Natural language query interface to search professor reviews  
- Semantic search using vector embeddings for precise retrieval  
- Aggregates and summarizes feedback from multiple sources  
- Helps students make informed decisions based on real reviews
